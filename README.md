# Nuolinga Update v2.1

## Добавлено
- `/verify` принимает числовой Telegram ID или `@username`; для username игрок должен хотя бы раз запустить бота.
- Серия правильных ответов, сбрасывается при неправильном ответе.
- Серия дней: засчитывается за день, когда игрок решает пример; пропуск календарного дня сбрасывает серию при следующем решённом примере.
- 8 достижений из списка.
- Галочка профиля; выдавать её может только Telegram-пользователь с username `@PlatoKiri_tg` командой `/verify USER_ID`.
- 11 класс с квадратными уравнениями и наградой 100 XP.
- Кнопки профиля и достижений.
- Миграция старой базы данных: существующие пользователи и XP сохраняются.

## Запуск
1. Откройте `.env`.
2. Замените `PASTE_YOUR_TELEGRAM_BOT_TOKEN_HERE` токеном от @BotFather.
3. Установите Python 3.11+.
4. Выполните `pip install -r requirements.txt`.
5. Запустите `python main.py`.

`TIMEZONE` задаёт часовой пояс для достижения «Не спящий». По умолчанию `UTC`; можно указать, например, `Europe/Paris` или `Europe/Moscow`.

## Важно
- Для выдачи галочки аккаунт администратора должен иметь username `PlatoKiri_tg`.
- Чтобы выдать галочку, администратор может отправить `/verify USER_ID` или `/verify @username`. Целевой пользователь должен хотя бы раз нажать `/start`, чтобы бот сохранил его username. После обновления старым пользователям нужно снова нажать `/start`.
- Достижение «Не везучий» проверяется, когда игрок возвращается после пропуска дня и его серия до пропуска была не меньше 25.
